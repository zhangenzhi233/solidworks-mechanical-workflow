# 原生出图与文件交付

工程图从最终零件或装配配置创建。用主视图交代形状，用投影视图标孔距及位置，用穿过轴线、孔心或承靠面的剖面解释内部关系。需要放大局部时保留索引。尺寸取自边、孔、轴或真实模型尺寸。检查剖切线的两个端点、箭头方向、剖线、单位、图号、比例和标题栏。展示图的颜色和剖面应来自相同模型和配置。输出 PDF 后按成图尺寸查看一次，检查标注与剖视方向是否好读。

**复查关联。** 在工作副本记下一个驱动量、要量的两处几何和一条图纸标注。只改该驱动量，重建。分别读回实际模型几何和原图的同一条标注，再恢复工作尺寸、保存并复开。角度按角度单位换算。SOLIDWORKS API 中常用几何长度为米，常用角度为弧度，具体属性按接口定义核对。

**使用现成自动化时。** 可用已安装的 `solidworks-automation-skill` 创建关联视图和导出图纸，也可直接在 SOLIDWORKS 界面完成。自动化按实际安装探测版本和模板，选对文档类型及配置。重建后从最终配合特征读回导程与方向。遇到 COM 返回问题先核对该方法自己的状态枚举或强类型签名。只操作本任务文档，恢复临时改动的应用首选项。[SOLIDWORKS 自动化项目](https://github.com/wzyn20051216/solidworks-automation-skill)

## 将原生工程搬到另一目录

1. 从最终装配或引用该装配的工程图运行 **Pack and Go（打包）**。按任务纳入关联工程图、子装配、零件和所需外部引用。记录顶层打开入口。存在同名零件时保持目录层级或用打包工具重命名并同步引用。
2. 把实际交付压缩包解压到新目录。用新会话或没有同名文档的会话打开解压件。需要验证迁移时，可让本任务的临时打包目录在复核时不可见。保留原工程与用户已打开的文档。
3. 对每个要交付的工作配置，核对实例数、抑制状态、完全解析的部件、实际加载路径及关键尺寸。工程图逐张查视图、引用的模型及配置，检查一个关联尺寸。采购件只提供轻化外形时标明简化程度。对依赖外部设计表、派生零件、图库或外观资源的项目，单独复开对应功能。
4. 同时交付 STEP、3MF 或展示图时，从同一配置导出，在目标程序读回单位、数量和功能尺寸。结论写明实开的软件版本，分清名义几何、运动检查、受力计算和实物试配。

## 检查已打开装配当前配置的路径

Windows 上的 `scripts/inspect_sw_assembly.py` 需要 Python 和 pywin32。先在 SOLIDWORKS 中**完全解析并打开**待检装配，选定配置。默认通过运行对象表连接已有会话，只读当前装配树。

```text
python scripts/inspect_sw_assembly.py "解压目录/总装.SLDASM" --root "解压目录"
```

若运行对象表没有暴露桌面会话，或想直接复开磁盘上的验证副本，可追加 `--open-readonly`。该模式可启动或连接 SOLIDWORKS，已经打开的同一路径会直接读取，新打开的副本按只读方式完全解析，查完关闭副本并恢复原活动文档。若从自己的自动化会话调用，也可以将已有的应用、装配对象以及两个绝对 Path 传入 `inspect_document(app, doc, assembly, root)`。

多版本并装且指定 SOLIDWORKS 2024 时，加 `--major 32` 选择它的 API 主版本。报告中的 `revision` 记录实际使用的版本。

机器上有 uv 时，可用 `uv run --isolated --python 3.12 --with pywin32 python scripts/inspect_sw_assembly.py "解压目录/总装.SLDASM" --root "解压目录" --open-readonly --major 32`。若报告带有打开警告，按 SOLIDWORKS 对应版本的警告码判断。遇到提示需要重建时，在验证副本中重建并重新量关键尺寸或角度。

如果所有文件都在包内，打开时仍可能报告内部文件 ID 不匹配、引用配置或外部依赖缺失。脚本会保留路径检查结果和原始警告码，同时将总结果置为需复核。此时先对照预期零件、配置及配合，用经过确认的文件修复引用，在工作副本保存受影响的文档，再关闭并从另一目录重开验证。已打开的文档无法追溯首次加载时的警告，报告中的 `open_warning_code` 为 `null`。[SOLIDWORKS 2024 打开警告释义](https://help.solidworks.com/2024/english/api/swconst/SolidWorks.Interop.swconst~SolidWorks.Interop.swconst.swFileLoadWarning_e.html)

用 `--pid` 可在同一文件被多个 SOLIDWORKS 进程同时打开时指定目标进程。每个活动文件型组件同时记录装配树给出的路径和已加载文档的实际路径。对有意抑制的实例计数。轻化、虚拟或无法取得文档的实例另列，需按具体结构复核。退出码 0 表示本配置中实际加载的文件型组件均在指定目录，1 表示发现外部引用，2 表示检查不完整。多个配置逐一选择后检查。该脚本不遍历工程图、零件内的外部引用或制造文件，按上面的相应步骤继续核对。
