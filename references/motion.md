# 装配、运动与间隙

先给固定件找安装基准，再判断每个活动件还应保留哪种运动。轴孔同心后，检查轴向是否已定位，是否应保留转动。平移件分别检查侧向定位、抗转和可用行程。一个手轮、丝杆与螺母的组合只需要一个独立运动输入。将本来刚性连接的件归入部装，再对移动的部装施加工作配合。工具、线束、盖子和装入路径可在需要时作为检查包络。

**验证输入对输出的关系。** 先根据机构独立算出预期值。单头丝杆每转进给一个导程，多头丝杆的导程等于螺距乘头数。将实际开度改半个或四分之一个导程，重新量钳口面距离和轴的转角，检查方向。转过整圈后外观看起来相同，分数圈能查出导程和正反方向错误。转轴用可识别的径向点或有方向的坐标轴读角度。切换配置后重新取得当下的组件、配合和尺寸。

**布置检查工况。** 固定装配可查一个位置。带运动的机构至少考虑端点、最近接近处和可能越过障碍的位置。摆臂在途中扫过立柱时，两个端点都可能很宽松。模型若要求覆盖整段行程，用连续碰撞检测、扫掠包络或带误差界的几何分析。离散结果标明采样姿态。按设计注明承靠、抵接及有意过盈的零件对与允许范围。回差、制造公差和受载变形按需求另查。

## 让人能在装配图中直接操作

1. 画出从输入件到从动件的运动链，列每个关节的转轴、移动方向和机械限位。将机架固定在底盘坐标系中。试验整机平移时，用外层装配固定环境，给整机保留所需的地面自由度。螺钉、固连电路板和外壳随所属刚体运动。
2. 在配置管理器检查角度驱动、固定组件、锁定旋转及刚性子装配。需要用手拖动的自由度可使用同轴加轴向止推、导轨或限位配合。跨层联动时，用柔性子装配或将活动件移到同一求解层。提升车轮时保留轴承、轮胎和紧固件在原有刚体中的归属，并核对提升前后的零件实例总数。
3. 四连杆和转向机构由输入臂驱动。两端销轴闭合后，量从动臂在左右端和若干中间角的实际姿态，再用杆长、销中心距独立复算。把用手拖动的限位配合与用于输入数值的驱动配合分在不同配置。切换后重新取得组件和配合。
4. 验收“能拖动”时，在约定的配置按住、移动并松开，观察从动件，记录前后实际姿态。若工具使用图形区鼠标事件，按下、移动、松开应取自同一视图坐标系，切换文档后重绑定。记录用户实际需要启动的程序。重新打开交付包再做一次操作。

如果限位数值正确，机构仍然锁住，先只放开一个输入，在轮端或摇臂末端施加有力臂的拖动。对小角度摇臂，可用离轴销中心点到固定平面的距离限制行程，横向变化量为半径乘摆角的正弦；选择距离随角度单调变化的工作区间。复测正、反方向和中途位置，读回销轴、刚体以及总装中实际显示的零件。在外部控制面板中，将一次输入的全部位姿取作同一份快照，防止鼠标回调恰在四轮更新途中改变数据。

## 推力、滚动与松手

- 先说明模型的自由度和已知物理量。推小车可以从平地纵向动力学开始，明确有效质量、推力、持续时间和滚阻的来源。转向几何由连杆求解。需要验证起伏路面、打滑或碰撞时，另建接触和载荷工况。
- 匀力保持一段时间后松手，分别记录释放瞬间的速度、无外推时的滑行距离和停止位置。常量滚阻下，可用功和动能或匀减速公式复算。做一次零输入及反向输入检查。把假设值与实测参数分别标在结果旁。
- 直行无滑移用 `s = r × θ` 复算，角度用弧度。半径 30 mm 的轮前进 47.124 mm 应转过四分之一圈。为轮辋选一个偏心孔或记号。左、右轴局部正方向可能相反。用车轮相对转向节或车架的变换读自转，再量世界坐标中的车身位移。弯道分别计算内外轮的路程。

将按运动顺序实读的直线位移和各轮局部角度写入 CSV。下面列名为 `travel_mm,left_deg,right_deg`，两轮半径均为 30 mm。第三个参数表示车轮向前滚时局部角度增加还是减少。

```text
python scripts/check_rolling.py straight.csv --wheel left_deg 30 1 --wheel right_deg 30 -1
```

相邻采样应小于半圈，包含一次前进和一次倒退。脚本逐段比较，退出码 0 为误差达标，1 为不一致，2 为读数不足或无法判定。把其中一列改为固定角度再运行，应检出锁死轮。转向时先计算每个轮心的独立轮程，再分别与该轮角度比较。

## 用分件 STEP 复算

`scripts/check_step_fit.py` 使用 Python 和 CadQuery，已在 CadQuery 2.6.1 验证。它检查给定各状态的全部实例对，对列出的关键对额外量距离。每实例输入一个有效闭合实体的 STEP 文件，模型几何以毫米导入。同一文件可作为多个实例。已经装配到位的分件可直接用单位位姿，也可给本地坐标的分件指定变换。

将下例存为 `fit.json`，路径相对它所在的目录。实例先绕 `rotation` 指定的局部轴线旋转，再按装配坐标平移。旋转点默认为局部原点。状态覆盖给定的位姿字段，其余字段继承实例默认值。各状态都从默认位姿出发。

```json
{
  "parts": {
    "摆臂": {"step": "arm.step"},
    "立柱": {"step": "post.step", "translate_mm": [20, 20, 0]}
  },
  "states": [
    {"name": "收起"},
    {"name": "斜置", "poses": {"摆臂": {"rotation": {"axis": [0, 0, 1], "degrees": 45}}}},
    {"name": "展开", "poses": {"摆臂": {"rotation": {"axis": [0, 0, 1], "degrees": 90}}}}
  ],
  "min_clearances": [{"pair": ["摆臂", "立柱"], "mm": 1.0}]
}
```

```text
python scripts/check_step_fit.py fit.json
```

机器上有 uv 时，也可用 `uv run --isolated --python 3.12 --with cadquery==2.6.1 python scripts/check_step_fit.py fit.json` 运行。该命令单独提供脚本依赖。

脚本只读输入，向标准输出写 JSON。退出码 0 表示所列工况及间隙要求通过，1 表示发现相交或间隙不足，2 表示输入、依赖或几何计算未能完成。输出中的体积阈值和长度误差是数值判据。零相交体积也可能是两面贴合。需要间隙的零件对要明确给出最小距离。对有意过盈要查明对应几何和允许量，保留脚本报告中的原始数值。

**用已知错误校验复杂配合。** 例如在工作副本把挡柱移进摆臂扫掠区，或把真实螺纹错开半周，看能否检出相交。恢复正确的相位或位置，再查正确工况。仿真使用简化螺纹时，可验证运动关系与外包络。要判断牙型啮合，需要真实牙型和独立的相位对照。

小台钳的实例中，手轮扫过底板，法兰碰到支座斜面。分别回到底板轮廓和支座让位特征修改，重查原来的姿态，并在相邻姿态确认没有新干涉。这个检查方法同样可以用于铰链、滑台或可开合的外壳。
