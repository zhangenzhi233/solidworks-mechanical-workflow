# 零件、基准和接口

**从摆放图开始。** 支架先画被支撑物的轮廓、支撑面和紧固方向。外壳先放实际内部件，再定板边到内壁、插头插拔行程及开盖方向。传动件先画共同轴线与工作行程。判断用哪一面起笔时，找能用最少尺寸说明主要轮廓、又能给后续特征稳定基准的视图。

| 形状或用途 | 适合的建模方式 | 用一次修改检验设计意图 |
|---|---|---|
| 两边对称的支架或叉耳 | 中心基准面、单侧特征和镜像，或中面拉伸。用孔中心距、耳板厚度和轴线位置驱动。 | 改中心距后，两端对称移动。再量孔径和端面间距。 |
| 轴套、轮毂、阶梯轴 | 画轴向半截面，标出回转轴和台阶端面，再做安装平面、键槽或工具槽。 | 改轴径或台阶长后，定位端面和相邻承靠面仍能装合。 |
| 外壳、板卡托盘 | 以板卡安装面和明确的一脚方向统一坐标。分别建板框、元件高度、插头连线及拔出包络。 | 选两个不对称的孔或接口核对左右、上下及镜像。改板宽后，检查柱位、板边和插头净空。 |
| 同规格重复孔或局部细节 | 先完成一个正确的孔、沉孔或切除，再由镜像或阵列控制分布。孔向导记录孔型和深度。 | 切剖面确认通孔和沉孔方向。测紧固件头、垫片、工具和装入方向。 |

关键孔优先引用安装面、定位轴、基准面或主草图。后加圆角的短边容易在改型后消失，确实要依赖它时，改尺寸后检查下游特征。保留有意活动的草图自由度，在交接时说明用途。导入外部 STEP 后标明哪些是导入实体，哪些是可编辑的原生特征。

**工艺跟着结构走。** 打印件关注分件方向、层间受力、桥接、支撑能否取出和热熔螺母的装入空间。配合间隙结合设备、材料和表面处理，用小样确定。机加工要查刀具能否进入、内角半径、贯穿及沉孔的加工方向。选用采购件时按完整规格对到厂家图或实物。需要交付 3MF 时，从同版模型生成，核对单位、包围尺寸、数量，并在目标切片器打开。

板卡来自嘉立创时，按项目里实际存在的 PCB 取板框、孔位、接口朝向和高度来源，再与机械坐标对应。可配合 `easyeda-pcb-workflow`、嘉立创官方 API 技能与 easyeda-agent 读取原工程。[官方接口](https://github.com/easyeda/easyeda-api-skill/blob/main/README.zh-Hans.md) · [easyeda-agent](https://github.com/zhoushoujianwork/easyeda-agent)
